# incoming/about: About the university

History, mission, contacts, regulations, academic calendar.

Put the files listed below in this folder, then run `ictkb intake` from the repository root.
Replace YYYY-MM-DD with the date you obtained the file. Keep the file name otherwise unchanged.
For several files of the same kind, add a part label after the topic, for example `about_<topic>~second-file_YYYY-MM-DD.pdf`.

## Files to place here

| Priority | Item | File name | From |
|---|---|---|---|
| P0 | Photo of the official signboard or letterhead showing the contact details | `about_contacts_YYYY-MM-DD.jpg` | Administration |
| P0 | Student handbook or academic regulations, complete and current (PDF or DOCX) | `about_academic-regulations_YYYY-MM-DD.pdf` | Registrar |
| P0 | Official signed academic calendar (PDF) to confirm the version on the website | `about_academic-calendar_YYYY-MM-DD.pdf` | Registrar |
| P0 | Calendar poster displayed on campus, if one exists | `about_academic-calendar_YYYY-MM-DD.jpg` | Registrar |
| P1 | Institutional brochure or prospectus (PDF) | `about_university-overview_YYYY-MM-DD.pdf` | Administration |
| P2 | University logo (PNG, transparent background) | `about_photos_YYYY-MM-DD.jpg` | Communications |
| P2 | Exterior photographs of the building from at least three angles | `about_photos_YYYY-MM-DD.jpg` | Communications |

Accepted: PDF, DOCX, XLSX, CSV, PNG, JPG. Convert .doc to .docx and .xls to .xlsx first. Photographs must be sharp and readable. Never place files with personal data here.
