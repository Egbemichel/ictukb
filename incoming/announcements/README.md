# incoming/announcements: Announcements

Current notices, closures, rescheduled classes.

Put the files listed below in this folder, then run `ictkb intake` from the repository root.
Replace YYYY-MM-DD with the date you obtained the file. Keep the file name otherwise unchanged.
For several files of the same kind, add a part label after the topic, for example `announcements_<topic>~second-file_YYYY-MM-DD.pdf`.

## Files to place here

| Priority | Item | File name | From |
|---|---|---|---|
| P0 | Poster images of current notices | `announcements_current_YYYY-MM-DD.jpg` | Communications or Registrar |

## Google Sheets for this category

- `announcements-current`: fill the template `templates/sheets/announcements-current.csv` (priority P0, Communications or Registrar).

Accepted: PDF, DOCX, XLSX, CSV, PNG, JPG. Convert .doc to .docx and .xls to .xlsx first. Photographs must be sharp and readable. Never place files with personal data here.
