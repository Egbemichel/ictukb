# incoming/programs: Programs

Faculties, departments, curricula, graduation requirements, thesis rules.

Put the files listed below in this folder, then run `ictkb intake` from the repository root.
Replace YYYY-MM-DD with the date you obtained the file. Keep the file name otherwise unchanged.
For several files of the same kind, add a part label after the topic, for example `programs_<topic>~second-file_YYYY-MM-DD.pdf`.

## Files to place here

| Priority | Item | File name | From |
|---|---|---|---|
| P0 | Official list of programs per faculty, or the programs brochure (PDF) | `programs_overview_YYYY-MM-DD.pdf` | Registrar or Deans |
| P1 | Organisation chart of faculties and departments | `programs_faculties-departments_YYYY-MM-DD.pdf` | Deans |
| P1 | Bachelor program regulations, if separate from the student handbook | `programs_bachelor_YYYY-MM-DD.pdf` | Registrar |
| P1 | Masters program regulations | `programs_masters_YYYY-MM-DD.pdf` | Registrar or Dean of postgraduate studies |
| P1 | PhD handbook | `programs_phd_YYYY-MM-DD.pdf` | Dean of research |
| P1 | Syllabus or course outline for each program (PDF or DOCX), one file per program | `programs_course-descriptions_YYYY-MM-DD.pdf` | Heads of department |
| P1 | Graduation requirements per program, if documented separately | `programs_graduation-requirements_YYYY-MM-DD.pdf` | Registrar |
| P1 | Thesis guidelines and thesis template | `programs_masters-thesis_YYYY-MM-DD.pdf` | Dean of postgraduate studies |
| P2 | PhD process description | `programs_phd-process_YYYY-MM-DD.pdf` | Dean of research |

## Google Sheets for this category

- `programs-curriculum`: fill the template `templates/sheets/programs-curriculum.csv` (priority P1, Heads of department).

Accepted: PDF, DOCX, XLSX, CSV, PNG, JPG. Convert .doc to .docx and .xls to .xlsx first. Photographs must be sharp and readable. Never place files with personal data here.
