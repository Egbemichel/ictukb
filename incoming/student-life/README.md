# incoming/student-life: Student life

Clubs, Student Union Government, events, sports.

Put the files listed below in this folder, then run `ictkb intake` from the repository root.
Replace YYYY-MM-DD with the date you obtained the file. Keep the file name otherwise unchanged.
For several files of the same kind, add a part label after the topic, for example `student-life_<topic>~second-file_YYYY-MM-DD.pdf`.

## Files to place here

| Priority | Item | File name | From |
|---|---|---|---|
| P1 | Club logos | `student-life_clubs_YYYY-MM-DD.jpg` | Student affairs |
| P1 | Student Union constitution | `student-life_sug_YYYY-MM-DD.pdf` | Student Union Government |
| P1 | Photograph of the executive list posted on campus | `student-life_sug_YYYY-MM-DD.jpg` | Student Union Government |
| P2 | Club creation form or rules, if written | `student-life_start-club_YYYY-MM-DD.pdf` | Student affairs |
| P2 | Election calendar or rules | `student-life_sug-elections_YYYY-MM-DD.pdf` | Student Union Government |
| P2 | Event posters | `student-life_events_YYYY-MM-DD.jpg` | Student affairs |

## Google Sheets for this category

- `student-life-clubs`: fill the template `templates/sheets/student-life-clubs.csv` (priority P1, Student affairs).
- `student-life-events`: fill the template `templates/sheets/student-life-events.csv` (priority P2, Student affairs).

Accepted: PDF, DOCX, XLSX, CSV, PNG, JPG. Convert .doc to .docx and .xls to .xlsx first. Photographs must be sharp and readable. Never place files with personal data here.
