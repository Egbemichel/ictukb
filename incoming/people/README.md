# incoming/people: People

Staff directory, heads of department, delegates, course lecturers.

Put the files listed below in this folder, then run `ictkb intake` from the repository root.
Replace YYYY-MM-DD with the date you obtained the file. Keep the file name otherwise unchanged.
For several files of the same kind, add a part label after the topic, for example `people_<topic>~second-file_YYYY-MM-DD.pdf`.

## Files to place here

| Priority | Item | File name | From |
|---|---|---|---|
| P2 | Official organisational chart | `people_org-chart_YYYY-MM-DD.pdf` | Administration |

## Google Sheets for this category

- `people-staff-directory`: fill the template `templates/sheets/people-staff-directory.csv` (priority P1, Administration).
- `people-heads-of-department`: fill the template `templates/sheets/people-heads-of-department.csv` (priority P1, Administration).
- `people-delegates`: fill the template `templates/sheets/people-delegates.csv` (priority P1, Student affairs or class delegates).

Accepted: PDF, DOCX, XLSX, CSV, PNG, JPG. Convert .doc to .docx and .xls to .xlsx first. Photographs must be sharp and readable. Never place files with personal data here.
