# incoming/erp: ERP system

Student-facing ERP flows, support, release notes.

Put the files listed below in this folder, then run `ictkb intake` from the repository root.
Replace YYYY-MM-DD with the date you obtained the file. Keep the file name otherwise unchanged.
For several files of the same kind, add a part label after the topic, for example `erp_<topic>~second-file_YYYY-MM-DD.pdf`.

## Files to place here

| Priority | Item | File name | From |
|---|---|---|---|
| P0 | ERP user manual and module list | `erp_overview_YYYY-MM-DD.pdf` | ERP team |
| P0 | Screenshots of every step of the first login, in order (hide any real password) | `erp_first-login_YYYY-MM-DD.jpg` | ERP team |
| P0 | Screenshots of the password reset flow, in order | `erp_password-reset_YYYY-MM-DD.jpg` | ERP team |
| P0 | Screenshots of every step of course registration, in order | `erp_course-registration_YYYY-MM-DD.jpg` | ERP team |
| P1 | Screenshots of the results screens | `erp_results_YYYY-MM-DD.jpg` | ERP team |
| P1 | Screenshots of the fee statement screens | `erp_fee-statement_YYYY-MM-DD.jpg` | ERP team |
| P1 | Screenshots of the timetable screens | `erp_timetable_YYYY-MM-DD.jpg` | ERP team |
| P1 | ERP user manual (PDF or DOCX) | `erp_user-manual_YYYY-MM-DD.pdf` | ERP team |
| P1 | Transcripts of any tutorial videos | `erp_user-manual_YYYY-MM-DD.pdf` | ERP team |
| P2 | Screenshots of the request screens | `erp_requests_YYYY-MM-DD.jpg` | ERP team |
| P2 | Release notes or changelog | `erp_release-notes_YYYY-MM-DD.pdf` | ERP team |

Accepted: PDF, DOCX, XLSX, CSV, PNG, JPG. Convert .doc to .docx and .xls to .xlsx first. Photographs must be sharp and readable. Never place files with personal data here.
