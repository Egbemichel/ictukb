# incoming/canteen: Canteen

Menu, prices, opening hours, payment methods.

Put the files listed below in this folder, then run `ictkb intake` from the repository root.
Replace YYYY-MM-DD with the date you obtained the file. Keep the file name otherwise unchanged.
For several files of the same kind, add a part label after the topic, for example `canteen_<topic>~second-file_YYYY-MM-DD.pdf`.

## Files to place here

| Priority | Item | File name | From |
|---|---|---|---|
| P1 | Photograph of the canteen sign with the hours | `canteen_hours_YYYY-MM-DD.jpg` | Canteen manager |
| P1 | Photograph of the menu board, once a week | `canteen_menu_YYYY-MM-DD.jpg` | Canteen manager |

## Google Sheets for this category

- `canteen-menu`: fill the template `templates/sheets/canteen-menu.csv` (priority P1, Canteen manager).

Accepted: PDF, DOCX, XLSX, CSV, PNG, JPG. Convert .doc to .docx and .xls to .xlsx first. Photographs must be sharp and readable. Never place files with personal data here.
