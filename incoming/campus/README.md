# incoming/campus: Campus and directions

Location, floor plans, rooms, offices, facilities.

Put the files listed below in this folder, then run `ictkb intake` from the repository root.
Replace YYYY-MM-DD with the date you obtained the file. Keep the file name otherwise unchanged.
For several files of the same kind, add a part label after the topic, for example `campus_<topic>~second-file_YYYY-MM-DD.pdf`.

## Files to place here

| Priority | Item | File name | From |
|---|---|---|---|
| P0 | Photograph of the entrance and the street frontage | `campus_location_YYYY-MM-DD.jpg` | Administration |
| P0 | Photograph of each office door and signage | `campus_office-directory_YYYY-MM-DD.jpg` | Administration |
| P1 | Floor plan of each floor, or a clear hand-drawn plan | `campus_floor-plans_YYYY-MM-DD.pdf` | Administration or facilities |
| P1 | Photograph of the stairs and the signage on each floor | `campus_floor-plans_YYYY-MM-DD.jpg` | Administration or facilities |
| P1 | Photographs of the library, the computer labs and the canteen | `campus_facilities_YYYY-MM-DD.jpg` | Administration |
| P1 | Photograph of each room door and signage | `campus_room-directory_YYYY-MM-DD.jpg` | Administration |

## Google Sheets for this category

- `campus-office-directory`: fill the template `templates/sheets/campus-office-directory.csv` (priority P0, Administration).
- `campus-room-directory`: fill the template `templates/sheets/campus-room-directory.csv` (priority P1, Administration).

Accepted: PDF, DOCX, XLSX, CSV, PNG, JPG. Convert .doc to .docx and .xls to .xlsx first. Photographs must be sharp and readable. Never place files with personal data here.
