# incoming/admissions: Admissions

How to apply, requirements, deadlines, application forms.

Put the files listed below in this folder, then run `ictkb intake` from the repository root.
Replace YYYY-MM-DD with the date you obtained the file. Keep the file name otherwise unchanged.
For several files of the same kind, add a part label after the topic, for example `admissions_<topic>~second-file_YYYY-MM-DD.pdf`.

## Files to place here

| Priority | Item | File name | From |
|---|---|---|---|
| P0 | Screenshots of every step of the online application portal, in order | `admissions_how-to-apply_YYYY-MM-DD.jpg` | Admissions office |
| P0 | Application guide or flyer, if one exists | `admissions_how-to-apply_YYYY-MM-DD.pdf` | Admissions office |
| P0 | Notice or page that states the deadlines | `admissions_deadlines_YYYY-MM-DD.pdf` | Admissions office |
| P1 | Required-documents checklist for Bachelor applicants | `admissions_bachelor-requirements_YYYY-MM-DD.pdf` | Admissions office |
| P1 | Blank Bachelor application form | `admissions_bachelor-requirements_YYYY-MM-DD.pdf` | Admissions office |
| P1 | Required-documents checklist for Masters applicants | `admissions_masters-requirements_YYYY-MM-DD.pdf` | Admissions office |
| P1 | Blank Masters application form | `admissions_masters-requirements_YYYY-MM-DD.pdf` | Admissions office |
| P1 | PhD application form and research proposal template | `admissions_phd-requirements_YYYY-MM-DD.pdf` | Admissions office or Dean of research |
| P1 | Transfer policy, if written | `admissions_transfer_YYYY-MM-DD.pdf` | Registrar |
| P1 | Every blank admission form (PDF or DOCX), one file per form | `admissions_forms_YYYY-MM-DD.pdf` | Admissions office |

Accepted: PDF, DOCX, XLSX, CSV, PNG, JPG. Convert .doc to .docx and .xls to .xlsx first. Photographs must be sharp and readable. Never place files with personal data here.
