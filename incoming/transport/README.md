# incoming/transport: Transport

University bus service, routes, fares.

Put the files listed below in this folder, then run `ictkb intake` from the repository root.
Replace YYYY-MM-DD with the date you obtained the file. Keep the file name otherwise unchanged.
For several files of the same kind, add a part label after the topic, for example `transport_<topic>~second-file_YYYY-MM-DD.pdf`.

## Files to place here

| Priority | Item | File name | From |
|---|---|---|---|
| P1 | Photograph of the bus poster | `transport_overview_YYYY-MM-DD.jpg` | Transport coordinator |
| P1 | Photograph of the route poster | `transport_schedule_YYYY-MM-DD.jpg` | Transport coordinator |

## Google Sheets for this category

- `transport-schedule`: fill the template `templates/sheets/transport-schedule.csv` (priority P1, Transport coordinator).

Accepted: PDF, DOCX, XLSX, CSV, PNG, JPG. Convert .doc to .docx and .xls to .xlsx first. Photographs must be sharp and readable. Never place files with personal data here.
