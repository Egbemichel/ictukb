# incoming/finance: Finance

Fees, installments, payment channels, clearance, refunds, scholarships.

Put the files listed below in this folder, then run `ictkb intake` from the repository root.
Replace YYYY-MM-DD with the date you obtained the file. Keep the file name otherwise unchanged.
For several files of the same kind, add a part label after the topic, for example `finance_<topic>~second-file_YYYY-MM-DD.pdf`.

## Files to place here

| Priority | Item | File name | From |
|---|---|---|---|
| P0 | Official fee schedule for the current academic year (PDF or XLSX) | `finance_fee-schedule_YYYY-MM-DD.pdf` | Finance office |
| P0 | Installment plan notice or the policy page that states it | `finance_installments_YYYY-MM-DD.pdf` | Finance office |
| P0 | Photograph of the official payment instructions posted at the finance office | `finance_payment-channels_YYYY-MM-DD.jpg` | Finance office |
| P0 | Official bank account notice | `finance_payment-channels_YYYY-MM-DD.pdf` | Finance office |
| P0 | Financial clearance form | `finance_clearance_YYYY-MM-DD.pdf` | Finance office |
| P1 | Refund policy, if written | `finance_refunds_YYYY-MM-DD.pdf` | Finance office |
| P1 | Scholarship and discount policy | `finance_scholarships_YYYY-MM-DD.pdf` | Administration or Finance office |
| P2 | Photographs or PDFs of current finance notices | `finance_fee-notices_YYYY-MM-DD.jpg` | Finance office |

Accepted: PDF, DOCX, XLSX, CSV, PNG, JPG. Convert .doc to .docx and .xls to .xlsx first. Photographs must be sharp and readable. Never place files with personal data here.
