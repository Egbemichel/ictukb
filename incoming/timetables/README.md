# incoming/timetables: Timetables

Class, exam and resit timetables.

Put the files listed below in this folder, then run `ictkb intake` from the repository root.
Replace YYYY-MM-DD with the date you obtained the file. Keep the file name otherwise unchanged.
For several files of the same kind, add a part label after the topic, for example `timetables_<topic>~second-file_YYYY-MM-DD.pdf`.

## Files to place here

| Priority | Item | File name | From |
|---|---|---|---|
| P0 | Combined course timetable (PDF). After intake, check the extracted text under content/timetables/_extracted/ and correct any garbled table rows | `timetables_classes_YYYY-MM-DD.pdf` | Timetable officer |
| P0 | Official examination timetable notice (PDF) | `timetables_exams_YYYY-MM-DD.pdf` | Timetable officer |

## Google Sheets for this category

- `timetables-exams`: fill the template `templates/sheets/timetables-exams.csv` (priority P0, Timetable officer).

Accepted: PDF, DOCX, XLSX, CSV, PNG, JPG. Convert .doc to .docx and .xls to .xlsx first. Photographs must be sharp and readable. Never place files with personal data here.
